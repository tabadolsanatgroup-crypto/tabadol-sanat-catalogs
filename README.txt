TABADOL SANAT — Digital Catalog Website

Contents:
- index.html: responsive Persian/English catalog landing page
- logo.png: supplied company logo
- 4 PDF catalog files

How to publish free:
1. Create/sign in to a GitHub account.
2. Create a new public repository named tabadol-sanat-catalogs.
3. Upload ALL files in this folder (index.html, logo.png, and all four PDFs) to the repository root.
4. In repository Settings > Pages, choose Deploy from a branch, select main and /(root), then Save.
5. GitHub will provide a public website URL after publishing. Open it on a phone to test all PDF links.
6. Only after the public URL works, create the permanent QR code pointing to that URL.

Important:
- Keep all filenames unchanged; the page links directly to them.
- This package is ready to publish but is not online yet.
- Do not print a QR code until the final public URL is confirmed.
